Last updated: 2026-05-26 · Developer: borastore · Contact: borastore.dev@gmail.com

English

Seoyul Metro is an offline-first Android train simulator for user-provided BVE/OpenBVE-style route and train packages.

Information We Collect

The app does not collect, transmit, sell, or share personal information.

Network Use

The signed release candidate does not request Android INTERNET permission and does not include advertising or analytics SDKs.

Local Data

The app stores settings, save files, route cache files, diagnostics, and imported route/train content locally on the device. These files remain in app-private storage or in locations selected by the user through Android file/folder picker flows.

Depending on user actions, such as exporting diagnostics, the app may write files to user-visible storage selected by the user or provided by Android.

Route And Train Packages

Users may select BVE/OpenBVE-style route or train packages from local storage. The app reads those files only to import, cache, diagnose, and run simulator content. The app does not upload those files.

Users are responsible for using legally available route and train content. The app does not include built-in third-party route or train packages in this release candidate.

Permissions

The app uses Android file/folder picker flows and app-private storage for content access. It does not request all-files access.

On Android 12 and below, the app requests READ_EXTERNAL_STORAGE up to maxSdkVersion=32 for legacy local content import.

System Backup

The signed release candidate enables Android system backup (android:allowBackup=true). If the user has device backup enabled, eligible app-private data may be included in the user's Android/Google device backup. The app itself does not operate an app server for backups.

Security, Retention, And Deletion

Imported content, cache files, save files, and diagnostics remain on the device until the user deletes imported content in the app, clears cache or diagnostics, clears app data in Android settings, or uninstalls the app. Because the app does not operate an app server and does not transmit user content, there is no server-side account or uploaded data to delete.

If Android/Google device backup is enabled by the user, eligible app-private data may be retained or removed according to the user's device backup settings.

Children

The app is intended for a general audience and does not knowingly collect information from children or any other users.

Changes

This privacy policy may be updated. Changes will be posted on the public privacy policy page at https://shuoak.github.io/seoyulmetro-privacy/privacy-policy.html.

Korean

서율 메트로는 사용자가 보유한 BVE/OpenBVE 형식의 노선 및 열차 패키지를 기기에서 불러와 실행하는 오프라인 우선 Android 철도 시뮬레이터입니다.

수집하는 정보

앱은 개인정보를 수집, 전송, 판매 또는 공유하지 않습니다.

네트워크 사용

서명된 릴리스 후보는 Android INTERNET 권한을 요청하지 않으며 광고 SDK나 분석 SDK를 포함하지 않습니다.

로컬 데이터

앱은 설정, 저장 파일, 노선 캐시 파일, 진단 파일, 가져온 노선/열차 콘텐츠를 기기 안에 로컬로 저장합니다. 이러한 파일은 앱 전용 저장소 또는 사용자가 Android 파일/폴더 선택기를 통해 선택한 위치에 남습니다.

진단 내보내기와 같은 기능을 사용하는 경우, 앱은 사용자가 선택했거나 Android가 제공한 사용자 표시 저장소에 파일을 쓸 수 있습니다.

노선 및 열차 패키지

사용자는 로컬 저장소에서 BVE/OpenBVE 형식의 노선 또는 열차 패키지를 선택할 수 있습니다. 앱은 해당 파일을 가져오기, 캐시 준비, 진단, 시뮬레이터 실행 목적으로만 읽으며 업로드하지 않습니다.

사용자는 합법적으로 이용 가능한 노선 및 열차 콘텐츠를 사용해야 합니다. 이 릴리스 후보에는 기본 내장 제3자 노선 또는 열차 패키지가 포함되지 않습니다.

권한

앱은 콘텐츠 접근을 위해 Android 파일/폴더 선택기와 앱 전용 저장소를 사용합니다. 모든 파일 접근 권한은 요청하지 않습니다.

Android 12 이하에서는 기존 로컬 콘텐츠 가져오기를 위해 READ_EXTERNAL_STORAGE 권한을 maxSdkVersion=32 범위로 요청합니다.

시스템 백업

서명된 릴리스 후보는 Android 시스템 백업(android:allowBackup=true)을 허용합니다. 사용자가 기기 백업을 켠 경우, 백업 가능한 앱 전용 데이터가 사용자의 Android/Google 기기 백업에 포함될 수 있습니다. 앱 자체는 별도의 백업 서버를 운영하지 않습니다.

보안, 보관 및 삭제

가져온 콘텐츠, 캐시 파일, 저장 파일, 진단 파일은 사용자가 앱에서 가져온 콘텐츠를 삭제하거나, 캐시 또는 진단 파일을 삭제하거나, Android 설정에서 앱 데이터를 지우거나, 앱을 제거할 때까지 기기에 남습니다. 앱은 서버를 운영하지 않고 사용자 콘텐츠를 전송하지 않으므로 서버 계정 또는 업로드된 데이터에 대한 별도 삭제 절차는 없습니다.

사용자가 Android/Google 기기 백업을 사용하는 경우, 백업 가능한 앱 전용 데이터는 사용자의 기기 백업 설정에 따라 보관되거나 삭제될 수 있습니다.

아동

앱은 일반 사용자를 대상으로 하며 아동 또는 그 밖의 사용자로부터 정보를 고의로 수집하지 않습니다.
